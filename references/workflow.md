# 新手收集材料

助手整理配置并运行脚本。不要让新手编辑 JSON，也不要让新手输入命令。已经给过的照片、姓名、婚期、分组名单、感谢文字和音乐直接沿用，不要再要一次。一次只问当前缺的那一项。

助手自己填的同意字段不是安全边界。脚本能拦住的是：没有清单、原话只是「跑一下」、文件不存在、音乐打不开、清单和文件对不上、输出目录已经存在。模型仍可能编造用户原话；这时要按用户真正发来的内容填写，不能为了跑通而改原话。

## 对用户怎么说

只把该说的那一句发给用户。检查命令、环境变量、字体完整路径、解压目录和自检缓存都不要写进主回复。

- `scripts/check_environment.py` 只检查工具链。通过时它自己的输出是「运行环境已就绪。」这不表示技能已经装进应用。
- 用户确实是在应用里刚安装成功时，助手才说：「技能已经装好。请发你要放进视频的照片。」
- 已经装过：不要再确认安装，不要重报版本或检查过程。缺什么就问什么。
- 不要给「打兼容补丁 / 装成常驻技能 / 直接出片」这种技术选择。已知的滤镜读法由脚本按本机 FFmpeg 版本处理。
- 依赖或兼容做不到时，用一句白话说明卡在哪里。不要为了短而瞒过失败，也不要问用户要不要修一个已知必须修的问题。
- 检查只读。不要自动安装软件，不要临时签名，不要去掉系统隔离。系统自己的安全提示留给用户授权。解释失败时，不要把绕过检查说成更安全。
- 技术字段只在出错或用户追问时再拿出来。不要贴 `FFMPEG=`、完整字体路径或 `.tools` 一类目录。

## 安装

用户只是装好或上传技能时，运行 `scripts/check_environment.py`。通过时它只打印上面那句短回复。详情在 `--details` 里，不要主动贴出。不导出视频。

## 模糊请求

「给我跑一下」「跑一下」「试一下」「做一个」「做一下」「试试看」「测试一下」都不是同意占位演示，也不是同意合成测试音，更不是确认导出。没有真实照片时，只请对方发照片。

## 本人的视频

1. 照片。没有照片就只问照片。
2. 新郎新娘姓名、婚期、分组名单、感谢文字。这一步里已经给过的不要重复要。姓名不猜测、不替换、不去重。
3. 音乐。还没指定时，只给三个短选项：原片同款、自己选歌，或明确静音。已经给过文件或已经选定，就不要再问一遍。

原片同款指五月天《如果我们不曾相遇》，只是曲名参考。包里没有这首歌，也不会提供下载。用户没把音频发来时，请对方上传其有权使用的文件，或发一段含有这段配乐的本地视频并明确说同意提取。不要从网站、技能包素材或猜到的私人路径里取歌。

从用户自己的视频提取时，取出的是整条音轨。里面如果有人声或环境声，会一起留下，这里不会拆成纯音乐。提取只是技术操作，不构成歌曲授权。

用户原话里明确出现「不要音乐」「先静音」「跳过音乐」或「明确静音」时，才可以静音。配置写 `"audio": null` 和 `"silent": true`。

本仓库的 MIT 许可只覆盖代码和包内画面素材，不包括第三方音乐。请使用你有权用于该视频的音频。

开发者测试用的短合成音只在源码的 `examples/music.m4a` 和明确要求的 `write-test-tone` 里，不放进安装包，也不作为客户默认音乐。

材料齐了以后，用清单里的白话汇总请用户确认。确认前不要导出。正式导出是 1920×1080。只有用户明确说预览时才用 960。

确认后由助手运行：

```bash
python3 -X utf8 scripts/gate.py manifest --state 状态.json --config 客户配置.json --out 新的输出目录 --manifest 清单.json
python3 -X utf8 scripts/render.py 客户配置.json --manifest 清单.json --out 新的输出目录
```

输出目录必须是新的，不能覆盖旧版本。

## 占位演示和合成测试音

演示不是第一步。用户要明确同意占位照片和化名，原话里同时有「同意」和「占位」。只同意占位、没有同意测试音时，仍要音乐文件或明确静音，不能自己合成一段声音来顶。

合成测试音还要另一次明确同意，原话里同时有「同意」和「合成测试音」。文件名只能是 `synthetic-test-tone.wav`。汇总必须写明「音乐是合成测试音，不是你的歌曲」。不要把它说成客户的 BGM。

仓库里的 `examples/` 只给开发者回归，不放进给客户安装的压缩包，也不能当客户默认配置。

## 停下来

照片、音乐或字体不存在，或音乐没有音轨时，脚本会停止并说明原因。把原因告诉用户。不要改成静音，不要换成效果图，不要生成声音顶上。
