# 效果依据与检查

已核对原片：星光为10fps帧动画，音波为PNG图形贴纸。v0.2 将星光做成 15fps、4 秒循环的可移植素材（本包使用的即是该文件）；音波为低亮度点状竖条装饰，不检测BGM节拍。

银黑唱片有粗同心纹路和对角反光。左侧星光避开照片圆形区域；右侧音波置于透明文字图层后方。星光、音波默认开启。用户明确选择静音时，星光和音波仍然显示；不要因此默认导出静音。

`record.png` 和 `wave.png` 按原片外观重新绘制。`stars.mov` 是 v0.2 使用的原星光文件，不是后来重做的替代品。这些文件不含私人婚礼素材、系统字体或剪映贴纸缓存。检查两帧的星芒变化、名单完整及音波可见；不能只凭导出成功验收。

公开包中的 stars.mov 为 v0.2 实际使用的原星光素材：1000×1080、15fps、4 秒循环、ARGB 透明通道，从画面左上角叠加。
