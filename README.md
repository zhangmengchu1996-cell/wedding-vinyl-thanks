# 黑胶婚礼致谢

用 AI 助手（WorkBuddy 或 Codex）就能做出婚礼结尾的黑胶致谢视频：银黑唱片轻摆、照片轮播、左侧星光、右侧音波、金白滚动名单。导出横屏 1080P（1920×1080）MP4。不会剪辑也可以用，不必打开剪映。

当前版本是 v0.2.1，只调整了向新手收集材料的顺序。画面和星光素材与 v0.2 相同。装好技能不会自动导出视频。

作者：抖音 / 小红书 @阿厨菇凉

## 效果是什么样的

- 中间一张银黑色的唱片在轻轻摆动，照片在唱片圆心里依次切换
- 左边有循环闪烁的星光，右边有音波装饰（音波是图形贴纸，不会跟着音乐节拍跳动）
- 右侧金色、白色的名字和感谢文字慢慢往上滚；名单很长时，视频会自动加长
- 开头停留约 8 秒，结尾至少停留 6 秒

## 使用前需要准备

- Python 3.9 或更高版本
- FFmpeg 和 FFprobe（命令行能直接运行 `ffmpeg`、`ffprobe`）
- 一款本机已安装的中文字体（macOS 上默认使用宋体 `/System/Library/Fonts/Supplemental/Songti.ttc`；如果提示找不到字体，在配置里把 `font` 改成你电脑上的中文字体路径）
- 目前渲染效果已在 macOS 上实测。v0.2.1 的提问顺序用本机脚本核对，没有另在 Codex 或 WorkBuddy 里重放一遍

按这个顺序准备材料：照片 → 新郎新娘姓名 / 婚期 / 分组名单 / 感谢文字 → 音乐文件。助手一次只问当前缺的一项，已经给过的不会再要。名单要自己核对，助手不会猜名字，也不会自动去重。

音乐需要你提供文件。只有你明确说「不要音乐」时，才会做静音，星光和音波仍会保留。助手不会自动静音，也不会自己编一段提示音。

## 安装

安装只表示技能已经放进助手，不是让它马上出片。装好后它应告诉你下一步发照片；不要期待它先交一支示例视频。

### WorkBuddy

1. 下载本仓库，把整个技能文件夹打成 zip（压缩包打开后，根目录就要能直接看到 `SKILL.md`，不要再多套一层文件夹）。
2. 打开左侧「专家·技能·连接器」，进入「技能」。
3. 点击「添加技能」→「上传技能」，把 zip 拖进去或选中即可。导入后会自动配置。
4. 装好后，助手只会确认已安装，并请你在要做自己的视频时先发照片。你准备好了再说：「帮我做一支黑胶婚礼致谢视频」。

请使用含 v0.2.1 说明的技能包。v0.2 发布页里的 `wedding-vinyl-thanks-public.zip` 仍是旧的提问方式，不能代替这次修复。

官方说明：[WorkBuddy 技能文档](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)

### Codex

1. 把整个技能文件夹放到官方推荐的个人技能目录：`~/.agents/skills/`（也就是电脑用户目录下的 `.agents/skills`）。文件夹里要包含 `SKILL.md`。
2. 放好后如果没出现，重启一下 Codex。
3. 装好后先发照片，或说：「帮我做一支黑胶婚礼致谢视频」。也可以用 `$` 提到 `wedding-vinyl-thanks`。只放进文件夹时，助手不应立刻导出视频。

官方说明：[Codex 技能文档](https://developers.openai.com/codex/skills/)

补充：更早的路径 `~/.codex/skills` 目前仍可能被识别，属于旧名称。对外安装请优先用 `~/.agents/skills`。

## 怎么用

跟助手说「帮我做一支黑胶婚礼致谢视频」，再按顺序把材料给它：

1. 照片（建议清晰、人脸完整；可以用 `focus_x` / `focus_y` 微调裁切，数值范围 0 到 1）
2. 新郎新娘的姓名、婚期、分组的亲友名单、感谢文字
3. 音乐文件。确定不要配乐时，直接说「不要音乐」

助手会整理配置并运行打包自带的脚本，你不用自己改 JSON 或输入命令。材料齐了以后，它会先重复一遍照片、文字和音乐文件名（或写明你已明确不要音乐），你确认后才导出。两条路都不用进剪映里自己拖素材。

演示不是必经步骤。只有你明确说要看示例时，助手才会用包里的占位图和化名做一版，并且会先说明那不是你的婚礼。

`examples/config.example.json` 是开发者示例（新郎张三、新娘李四，亲友名为化名，照片是占位图），只用来看格式和做测试。不要把它当成你的成片。客户视频不要使用这里的照片、人名和 `examples/music.m4a`。

依赖可以单独检查，不会因此导出示例。助手可以运行 `python3 -X utf8 scripts/render.py --check-deps`。

## 出片后请自己检查

- 看开头、中间、结尾，以及每一张照片出现的那一段
- 脸有没有被切到
- 姓名是否完整、有没有被拆开
- 结尾是否至少停满 6 秒
- 在同一张照片上，隔半秒以上暂停两帧，确认星光有在闪
- 音波看不看得见、会不会太亮
- 还没试听之前，不要只凭画面判断配乐是否合适。你明确要求静音时，成片没有音乐是正常的

## 素材说明

技能运行必须带上 `assets/record.png`、`assets/stars.mov`、`assets/wave.png`。

- `record.png`：银黑唱片圈，800×800 透明 PNG
- `wave.png`：右侧点状竖条音波装饰，820×330 透明 PNG
- `stars.mov`：v0.2 实际使用的原星光素材，1000×1080、15 帧/秒、4 秒循环、带透明通道（ARGB）。渲染时从画面左上角叠加，只覆盖左侧，右侧文字区不受影响。

`record.png` 和 `wave.png` 是按原片外观重新绘制的可移植素材，不是婚礼现场照片，也不含系统字体或剪映贴纸缓存。`stars.mov` 使用的是本机 v0.2 成片里那份原星光文件，不是后来重新生成的替代品。
