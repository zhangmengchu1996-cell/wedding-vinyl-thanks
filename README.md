# 黑胶婚礼致谢

用 AI 助手就能做婚礼结尾的黑胶致谢视频：银黑唱片轻摆、照片轮播、左侧星光、右侧音波、金白滚动名单。导出横屏 1080P（1920×1080）MP4。不必打开剪映。

当前版本是 v0.2.2。画面和星光素材与 v0.2 相同。装好后助手只会说已经装好，并请你发照片，不会让你选择打补丁或安装方式。

作者：抖音 / 小红书 @阿厨菇凉

给 Codex 用的安装包和给 WorkBuddy 用的安装包是两个压缩包，根目录都直接是 `SKILL.md`。不要用其中一个覆盖另一个的原版。

## 效果是什么样的

- 中间一张银黑色的唱片在轻轻摆动，照片在唱片圆心里依次切换
- 左边有循环闪烁的星光，右边有音波装饰（音波是图形贴纸，不会跟着音乐节拍跳动）
- 右侧金色、白色的名字和感谢文字慢慢往上滚；名单很长时，视频会自动加长
- 开头停留约 8 秒，结尾至少停留 6 秒

## 使用前需要准备

- Python 3.9 或更高版本
- FFmpeg 和 FFprobe（命令行能直接运行 `ffmpeg`、`ffprobe`）
- 一款本机已安装的中文字体。macOS 上默认宋体；找不到时把配置里的 `font` 改成你电脑上的字体路径
- 助手可以运行 `python3 -X utf8 scripts/check_environment.py` 做检查。检查不会出片，也不会安装或替换系统里的 FFmpeg

按这个顺序准备材料：照片 → 新郎新娘姓名 / 婚期 / 分组名单 / 感谢文字 → 音乐文件。已经给过的不会再要。名单要自己核对，助手不会猜名字。

没有音乐文件时不会自动做静音。只有你明确说「不要音乐」，才会导出静音，星光和音波仍会保留。

「给我跑一下」「试一下」「做一个」只表示你想开始，不是同意用占位图，也不是同意合成一段测试音。助手会先向你要照片。

## 安装

### Codex

1. 使用 Codex 安装包，或把含有 `SKILL.md` 的技能文件夹放到 `~/.agents/skills/`。
2. 放好后如果没出现，重启 Codex。
3. 装好后助手只确认已安装，并请你发照片。你准备好了再说：「帮我做一支黑胶婚礼致谢视频」。

官方说明：[Codex 技能文档](https://developers.openai.com/codex/skills/)

更早的路径 `~/.codex/skills` 仍可能被识别。对外安装优先用 `~/.agents/skills`。

### WorkBuddy

1. 使用 WorkBuddy 安装包。压缩包打开后，根目录就要能直接看到 `SKILL.md`。
2. 打开「专家·技能·连接器」里的「技能」，选择「添加技能」→「上传技能」。
3. 装好后助手只检查依赖并请你发照片，不会先导出一支视频。

这个包的名称仍是 `wedding-vinyl-thanks-workbuddy`，显示名仍是「黑胶婚礼致谢 · 星光音波版」。不要拿 Codex 包覆盖它。

官方说明：[WorkBuddy 技能文档](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)

v0.2 和只改说明的 v0.2.1 测试包不要再当作这次的安装包。

## 怎么用

1. 发照片（清晰、人脸完整）
2. 发新郎新娘姓名、婚期、分组名单和感谢文字
3. 发音乐文件。确定不要配乐时，直接说「不要音乐」

材料齐了以后，助手会用白话重复照片数量、文字和音乐文件名，或写明你已明确不要音乐。你确认后才导出。你不用改 JSON，也不用自己输入命令。

只有你明确同意，才可以看占位演示。合成测试音还要你另外同意，并且会标明那不是你的歌。

源码仓库里的 `examples/` 只给开发者做回归，不在给客户的安装包里。

## 出片后请自己检查

- 看开头、中间、结尾，以及每一张照片
- 脸有没有被切到，姓名是否完整
- 结尾是否至少停满 6 秒
- 同一张照片上隔半秒以上看两帧，确认星光有在闪
- 音波是否可见、会不会太亮
- 还没试听之前，不要只凭画面判断配乐。你明确要求静音时，成片没有音乐是正常的

## 素材说明

技能运行必须带上 `assets/record.png`、`assets/stars.mov`、`assets/wave.png`。

- `record.png`：银黑唱片圈，800×800 透明 PNG
- `wave.png`：右侧点状竖条音波装饰，820×330 透明 PNG
- `stars.mov`：v0.2 实际使用的原星光素材，1000×1080、15 帧/秒、4 秒循环、带透明通道（ARGB）

这三份文件与 WorkBuddy v0.2.0 原包的哈希一致，v0.2.2 没有更换。
